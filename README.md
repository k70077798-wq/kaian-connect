# KAIAN Connect

اصنع لي منصة تواصل اجتماعي فخمة واحترافية تحمل جميع الميزات الاحترافيه والحديثه والتصميم الانيق وبجمع الصفحات والخدمات صفحات التسجيل والدخول  واضافة كل شي موجود في  منصة فيسبوك واضافة لوحة التحكم للتحكم بكل شي موجود داخل المنصة وبالمستخدمين وتوثيق حسابات المستخدمين وايضا الاعلانات والحملات والصفحات والمجموعات لوحة التحكم تضهر فقط عند الدخول بهذه admin123@admin.com الباسورد admin123 واليك صور مرفقه لتطابق التصميم والشكل--واجعل المنصة تعمل سريعا بدون تأخير او انتضار عندما يضغط المستخدم على زر او اي شي يفتح سريع --استخدم الله العربية والخط المستخدم في فيسبوك اول ماتفتح المنصة بالمضهر الفاتح وبعد  الدخول او التسجيل يمكن للمستخدم اختيار الوضع  تجاوب مع جميع الشاشات والهواتف اسم المنصة KAIAN
